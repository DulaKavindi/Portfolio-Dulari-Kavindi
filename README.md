# Dulari Kavindi - Personal Portfolio Website

A modern, responsive personal portfolio website showcasing my software engineering projects, work experience, technical skillset, and resume.

Built with **React.js**, **Bootstrap**, and styled with an elegant dark-purple theme with interactive particle effects.

---

## 🚀 Features

- **Multi-Page Layout**:
  - **Home**: Brief introduction with typewriter effect and social links.
  - **About**: Professional bio, technical skillset badges, and tool stack.
  - **Experience**: Industry work experience timeline and internship details.
  - **Projects**: Showcase of featured full-stack and frontend projects with live GitHub links.
  - **Resume**: Interactive embedded PDF viewer displaying both pages of my CV with download capability.
- **Modern Responsive Design**: Optimized for desktops, tablets, and mobile devices.
- **Interactive UI**: Particle effects background, smooth transitions, and hover animations.

---

## 🛠️ Built With

- **Frontend**: React.js, React Router v6, React-Bootstrap, HTML5, CSS3
- **Icons & Effects**: React Icons, TSParticles, Typewriter Effect
- **PDF Viewer**: React-PDF
- **Styling**: Custom CSS with Dark Purple Aesthetic

## 💻 Getting Started Locally

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (Node 16+ recommended).

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/DulaKavindi/Portfolio-Dulari-Kavindi.git
   cd Portfolio-Dulari-Kavindi
   ```

2. **Install dependencies:**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Start the development server:**
   ```bash
   npm start
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Build for Production

To create an optimized production build:

```bash
npm run build
```

To serve the production build locally:
```bash
npx serve -s build
```
